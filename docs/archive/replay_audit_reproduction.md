# Authoritative Replay-Audit Reproduction

The aligned release and the broad universe probe were generated by two config snapshots. Their separate config hashes are intentional and match their manifests.

```powershell
python scripts/legacy/run_replay_audit.py build --config config/replay_audit_aligned_v1.json --release data/releases/replay_audit_v1 --output outputs/replay_audit_v1 --offline
python scripts/legacy/run_universe_probe.py --config config/replay_audit_v1.json --release data/releases/replay_audit_v1 --offline
python -m compileall -q src scripts tests
python -m unittest discover -s tests -v
```

- `config/replay_audit_aligned_v1.json` has canonical SHA-256 `17c1b467587556d3ac767235b8abba7032cc649c5b6013814818d3237f629b72`, matching `data_manifest.json`.
- `config/replay_audit_v1.json` includes `universe_raw_dir` and matches `universe_probe_manifest.json` (`0826b53807d6c4cab08d8022c81e59ae1651babb3699174a3fae9d9abb73b9a3`).

Required ignored raw archives:

- `data/raw/findata/replay_audit_v1`
- `data/raw/findata/replay_audit_v1_universe`

The core builder owns the aligned CSVs, README, `data_manifest.json`, and aggregate outputs. The universe builder owns `market_universe_probe.csv`, `universe_probe_summary.json`, and `universe_probe_manifest.json`. Builder manifests deliberately ignore co-located files owned by the other builder.
